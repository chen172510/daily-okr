# 周星星 · 桌面宠物（Windows）

行醒的桌面伙伴：一个**透明、置顶**的小人，会沿屏幕底部来回走，可以拖动，点它会换配件并说句话。

## 运行（开发）

```bash
cd desktop-pet
npm install
npm start
```

## 打包成 .exe

```bash
npm run dist
```

会在 `dist/` 生成绿色版 `周星星-桌宠-1.0.0.exe`（双击即用，无需安装）。

## 操作

- **拖动**：按住小人拖到任意位置
- **单击**：随机换配件 + 说一句话
- **托盘图标**：让它安静/继续走动、回到屏幕中间、退出

## 素材

- `assets/pet.jpg`：人物形象（替换成你自己的图即可，比例 1358×1280 最佳）
- `pet.js` 里的 `PROPS`：配件的位置与造型，可按需增删
